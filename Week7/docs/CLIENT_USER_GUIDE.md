# Client User Guide

Call the assigned VAPI number and describe a buying, rental, commercial, or
investment requirement naturally in Urdu, English, or UrduLish. Give location,
budget, property type, and bedrooms progressively. Ask for verified details or
request a visit. Sara confirms appointments only after the workflow succeeds.

For corrections, say the new value directly. For a failed tool, wait and retry
or request a human representative. Do not share passwords, payment-card data, or
unnecessary personal information. Contact an administrator if the agent repeats
errors, provides silence, or cannot reach property/calendar systems.
