AFL DAY 5 — HOW TO RUN

1. Extract the ZIP.

2. Open the extracted project folder in File Explorer.

3. Put your real Week 6 prediction artifacts in the project root:
   - match_winner_model.joblib
   - top_player_model.joblib
   - team_snapshots.parquet
   - player_snapshots.parquet

4. Create a virtual environment and install requirements.
   Windows PowerShell:
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt

5. Copy .env.example to .env and put your real OPENROUTER_API_KEY in it.

6. First test:
   python -m pytest -q

7. Run the CLI:
   python day5_graph.py

8. Run the API in a second terminal:
   uvicorn api:app --reload

9. Open the API health page:
   http://127.0.0.1:8000/health

10. Run the Streamlit UI in a third terminal:
    streamlit run streamlit_app.py

11. Open the Streamlit URL shown in the terminal, normally:
    http://localhost:8501

12. Run the full evaluation:
    python evaluation.py

13. Check:
    evaluation_results.csv
    monitoring.jsonl
