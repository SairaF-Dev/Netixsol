# API reference

Generated by `python scripts/export_api_docs.py` from the running FastAPI app (`ilm/api/main.py`); the machine-readable version is [openapi.json](openapi.json), and a live, clickable version is at `/api/docs` on any running server.

**Auth.** `POST /api/auth/login` sets an httpOnly cookie `ilm_session` (a signed JWT, 8 hours, SameSite=Lax, Secure in production). Every other call sends it automatically from the browser. From a script, send it as a `Cookie` header (see `ilm/api/loadtest.py`).

**Hidden tests never leave the server.** Exercise pages carry visible tests only; a submission result says how many hidden tests failed and in what way (wrong value, error, too slow), never their input or answer (`service.public_result` is a whitelist).

## Auth

| method | path | who | what | body |
|---|---|---|---|---|
| GET | `/api/health` | public | Is the server up? |  |
| POST | `/api/auth/login` | public | Log in; sets the session cookie. Same answer and timing for an unknown user and a wrong password. | `username` string [max 40, min 1]; `password` string [max 200, min 1] |
| POST | `/api/auth/logout` | public | Log out; clears the session cookie. |  |
| GET | `/api/me` | any logged-in user | Who is logged in (username, name, role). |  |

## Student

| method | path | who | what | body |
|---|---|---|---|---|
| GET | `/api/me/path` | student | The student's learning plan: mastered and weakest concepts, the ordered path with time estimates. |  |
| GET | `/api/exercises` | any logged-in user | All coding exercises in learning order (function, concept, difficulty, lesson). |  |
| GET | `/api/exercises/{qid}` | any logged-in user | One exercise: task, starter code, visible tests, number of hidden tests; for a student also their last 5 runs. | qid |
| POST | `/api/submissions` | student | Submit code to grade. Returns an id at once (202); grading runs in the sandbox in the background. | `exercise` string [max 60]; `code` string [max 20000] |
| GET | `/api/submissions/{sid}` | student | A submission's status (queued, running, done, error) and, when done, the mark and feedback. | sid |
| GET | `/api/practice/next` | student | The next MCQ or short-answer question on a concept (untried ones first). The key is not sent. | concept (query) |
| POST | `/api/answers` | student | Grade an answer on the server: right or wrong, the misconception behind a wrong option, mastery before and after. | `question` string [max 60]; `choice` integer/null (optional); `text` string/null (optional) |

## Tutor

| method | path | who | what | body |
|---|---|---|---|---|
| POST | `/api/tutor/ask` | student | Ask the Socratic tutor a course question; answered from course sources, with lesson links. | `message` string [max 1500, min 1]; `language` string (optional) [pattern ^(auto|english|urdulish)$] |
| POST | `/api/tutor/hint` | student | One rung of the hint ladder for an exercise (1 question, 2 concept, 3 partial hint, 4 similar example). Never the solution. | `exercise` string [max 60]; `code` string (optional) [max 20000]; `message` string (optional) [max 1500]; `level` integer (optional) [≥ 1.0, ≤ 4.0]; `language` string (optional) [pattern ^(auto|english|urdulish)$] |

## Teacher

| method | path | who | what | body |
|---|---|---|---|---|
| GET | `/api/class/overview` | teacher | Class KPIs, weakest concepts and the section x concept mastery heatmap. |  |
| GET | `/api/class/at-risk` | teacher | Students the dropout model flags this week, with the reason in words and a suggested action. |  |
| GET | `/api/review` | teacher | Items waiting for a teacher: possible copying, low marks, tampering flags. |  |
| GET | `/api/review/{item_id}` | teacher | One review item in detail (for copying: both programs side by side, matching lines). | item_id |
| POST | `/api/review/{item_id}` | teacher | Record the teacher's decision on a review item. Nothing is ever decided automatically. | `decision` string [max 60]; `note` string (optional) [max 500] |
| GET | `/api/questions/health` | teacher | Question bank health: IRT evidence per question, retire/relabel suggestions, generated-question pipeline. |  |
| POST | `/api/questions/{qid}/decision` | teacher | Record a teacher's decision on a question (Retire, Relabel with a level, Keep). | `decision` string [max 20]; `level` integer/null (optional) |
| GET | `/api/tutor/safety` | teacher | Tutor evaluation runs and live usage (metadata only; no student text is stored). |  |
| GET | `/api/impact` | teacher | Impact numbers: adaptive vs fixed, dropout model, grading agreement, safety, the A/B test design. |  |

## Errors

| status | when | body |
|---|---|---|
| 401 | not logged in, or the session ended (8 hours) | `{"detail": "Please log in."}` |
| 403 | logged in with the wrong role (a student calling a teacher endpoint) | `{"detail": "This page is for teachers."}` |
| 404 | unknown exercise, submission, question or review item; another student's submission | `{"detail": "No such ..."}` |
| 422 | invalid body (too long, missing field, unknown decision) | FastAPI validation detail |
| 429 | per-student limit: 12 code runs a minute; tutor 8 a minute and 80 a day | `{"detail": "..."}` |
| 503 | tutor unavailable (no API key, or the free model quota is used up) | `{"detail": "..."}` |
