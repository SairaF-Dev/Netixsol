# ShopKaro — Reports & Evaluation Artifacts

This directory archives executive summaries, milestone reports, benchmark comparisons, and generated analytical figures.

---

## Directory Organization

```
reports/
├── figures/                # Exported visualization figures, charts, and plots
└── README.md               # Reports directory documentation (this file)
```

---

## Intended Purpose

- **Milestone Deliverables:** Structured Markdown and PDF summaries covering exploratory findings, recommender benchmarking, demand forecast evaluations, and A/B test experiments.
- **Model Evaluation Benchmarks:** Comparative performance tables (e.g., HitRate@10, NDCG@10, MAP, WAPE, RMSE) across iterative model baselines.
- **Figures & Visualizations (`reports/figures/`):** High-resolution SVG/PNG charts produced by notebooks and evaluation pipelines.
