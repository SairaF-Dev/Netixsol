# ShopKaro — Model Artifacts & Registry

This directory stores trained machine learning models, preprocessors, vector indexes, and evaluation metadata.

---

## Intended Purpose

- **Artifact Persistence:** Houses trained weights, pipeline transformers, similarity matrices, and FAISS/BM25 indexes generated by ShopKaro training pipelines.
- **Artifact Formats:** Recommended serialization formats include `.joblib`, `.safetensors`, `.onnx`, or `.json` for metadata.
- **Metadata Documentation:** Every serialized model checkpoint must be paired with a corresponding model card located in `docs/model_cards/` detailing training data provenance, hyperparameters, evaluation metrics, and operational limitations.

---

## Storage & Version Control Rules

> [!IMPORTANT]
> **Trained model binaries must never be committed to Git.**
> All files in this directory (except `.gitkeep` and `README.md`) are explicitly excluded by `.gitignore`. For production environments, model weights are pulled from an artifact registry or object storage bucket (e.g., S3, GCS, or MinIO).
